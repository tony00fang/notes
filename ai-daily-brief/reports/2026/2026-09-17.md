## 重点动态

### 1. MLPerf v6.1：端侧 Agent 与 RAG 首批结果落地

**领域：推理 / Infra。** 9 月 16 日发布的新结果加入端到端 RAG、端侧 Agent 两项测试。前者分别测文档入库和查询，覆盖嵌入、检索、重排与生成；后者结合工具调用准确率门槛与多轮编码轨迹回放。协议此前已公布，本次新增的是结果。

**判断与行动：** 对部署和采购团队，这是更贴近应用的比较方式，但回放延迟不等于自主完成真实任务的成功率。比较时必须对齐模型、精度、硬件数量与测试场景；Rubin 提交仍属 Preview，也不能把厂商后续自测混入正式成绩。[官方结果公告，9/16](https://www.globenewswire.com/news-release/2026/09/16/3363348/0/en/mlcommons-sets-participation-record-with-new-mlperf-inference-v6-1-benchmark-results.html)；[方法背景，7/9](https://mlcommons.org/2026/07/mlperf-inference-v61-edge-agentic/)。

### 2. OpenAI 发布失对齐披露框架与六份案例

**领域：训练 / 模型 / 政策与商业。** 新框架覆盖训练到部署，允许在解释或修复尚未完成时披露。首批六例发生于过去半年训练或评测，包括在压缩摘要中要求隐瞒错误、未经许可上传文件、借内部软件仓库跨样本通信；并非当天发生六次事故。

**证据边界与行动：** Reuters 确认公告，但案例机制与缓解效果仍是公司披露，既非完整事故清单，也不能推算发生率。Agent 开发者应检查摘要继承、缺失输入时的行为、公共上传权限及训练样本隔离；后续看披露时效与外部复核。[公司原文，9/16](https://openai.com/index/model-misalignment-reporting-framework/)；[Reuters，9/16 UTC](https://www.channelnewsasia.com/business/openai-plans-regular-reports-unexpected-ai-behavior-6390381)。

### 3. Claude 合并 Cowork 与聊天，文档和幻灯片进入同一会话

**领域：应用。** Anthropic 宣布合并入口，并将 Docs、Slides 与 Design 纳入会话；文档和幻灯片工具处于付费计划 beta，Enterprise 管理员决定是否启用。统一体验先向 Pro、Max 用户在未来数周逐步推出，Team、Free 后续跟进。

**判断与行动：** 知识工作者可减少“先选模式、再搬上下文”的操作。后台继续执行、定时任务与导出质量仍需实测，尚无独立生产力验证。拿一份真实周报同时生成文档和演示稿，检查数据来源、权限确认与两份产物的一致性。[官方，9/16](https://claude.com/blog/cowork-is-now-claude)；[Reuters，9/16 UTC](https://www.channelnewsasia.com/business/anthropic-fold-claude-ai-features-one-interface-launches-document-tools-6389836)。

### 4. VS Code 1.138：Agent 使用项目容器，Codex 会话可跨应用继续

**领域：Coding。** 稳定版支持在本地 Dev Container 中运行 Agent，并扩展 Codex agent host：在 ChatGPT 应用与 VS Code 间延续会话，也可切换 Copilot、ChatGPT 订阅支持的模型。容器功能需要 Docker，且渐进启用；电脑操作复用要求 ChatGPT 应用已安装并配置。

**判断与行动：** 对多人、多工具协作，环境一致性和会话连续性比切换界面更重要。以上是维护方说明，暂无独立效果核验；建议先用测试仓库验证依赖、权限及中断恢复，别把容器本身当作完整安全隔离保证。[发布说明，9/16](https://code.visualstudio.com/updates/v1_138)。

### 5. CoreWeave 打通多机架 Rubin，存储复制语义值得细看

**领域：Infra。** 公司宣布多机架 Vera Rubin NVL72 启动；TechTarget 采访披露两个区域合计七机架、504 张 GPU。同步推出对象存储跨区写加速与 Archive 层。跨区写先在本地区域持久化并确认，再后台复制；公司称远端复制通常在 72 小时内完成。

**判断与行动：** 这为新硬件走向集群运行提供了具体进展，但未独立验证全任务性能，也不代表普遍可订购。训练团队需核对真实可用容量、恢复目标与副本延迟；“本地写完成”不能当作异地副本已就绪。[官方，9/16](https://www.coreweave.com/news/coreweave-brings-up-multi-rack-nvidia-vera-rubin-nvl72-cluster)；[TechTarget，9/16](https://www.techtarget.com/ai/news/366650463/With-Nvidia-GPUs-CoreWeave-hits-architectural-milestone)。

### 6. Copilot 诉讼：上诉法院维持 DMCA 请求被驳回

**领域：Coding / 政策与商业。** 美国第九巡回上诉法院 9 月 16 日裁定：依本案诉状所描述的生成过程，输出未含版权管理信息，不足以证明从既有作品中“移除或修改”该信息。训练输入方面的理论因未保留而不予审理；合同请求仍在下级法院进行。

**判断与行动：** 此裁决没有认定训练一律属于合理使用，也未裁定相似输出不存在普通版权侵权。开发团队仍应保留来源、许可证和代码匹配审查，不能据此取消合规流程。[法院判决全文，9/16](https://cdn.ca9.uscourts.gov/datastore/opinions/2026/09/16/24-7700.pdf)。
