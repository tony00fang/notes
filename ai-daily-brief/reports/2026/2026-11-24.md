## 重点动态

### 1. GLM-5.4：用循环深度扩展编程能力

**领域：模型 / 训练 / 推理｜11 月 23 日发布。** Z.ai 英文公告介绍其首款 Loop Transformer 旗舰：将 GLM-5 的 28 层执行两遍，通过继续训练改造已有基座，并共享部分 KV 与稀疏注意力索引。Coding Plan、ZCode 和 Chat 已提供入口，普通 API 标为 coming soon，权重等待安全强化后释放。

**公司主张与判断：**“达到更大模型水平”尚无充分独立核验。文中输出长度缩短的消融来自 30B 实验，不能直接外推到旗舰；官方也承认可能陷入过长思考。对开发者，最有价值的是在固定超时、预算和测试集下比较完成率、重试次数及总耗时，而非只看输出速度。**建议小范围试用，暂不按开放权重模型规划部署。** [官方技术说明，11/23](https://z.ai/blog/glm-5.4)

### 2. Claude Ship：修复与审批成为可配置工作流

**领域：Coding / 应用｜11 月 23 日发布。** Anthropic 将已有 Code Review 与 beta 阶段的 PR Steward、Claude Approvals 组合，面向 Team、Enterprise 的 GitHub 仓库。Steward 处理 CI、冲突和审查反馈，本身不批准或合并；Approvals 按仓库政策作出审批决定，仍受权限与分支规则约束。

**影响与判断：**工程瓶颈开始从写代码转向验证和授权，但内部提效数据属于公司自评，尚不能证明跨团队效果。功能按 token 产生费用，观察模式也可能收费，且不支持 ZDR、HIPAA 配置及客户管理加密密钥的组织。建议选择小仓库先运行 observe 模式，保留关键路径人工审核，记录误批与回退。 [官方发布，11/23](https://claude.com/resources/articles/introducing-claude-ship)

### 3. 英伟达恢复黄仁勋职务，调查继续

**领域：Infra / 政策与商业｜11 月 23 日新披露。** 公告宣布恢复黄仁勋总裁、CEO 及董事职务；8-K 明确董事会决定实际在 **11 月 22 日即时生效**，未列小时。Kress 继续任 CFO，Jones 留任董事长。公司同时表示独立委员会调查将继续，开始招聘首席合规官，并继续配合政府调查。

**影响与判断：**这为芯片路线、客户关系及生态投资恢复领导连续性，但“复任不构成国家安全风险”是董事会基于政府意见的判断，不代表出口许可或调查结论改变。云厂商与采购方仍应跟踪具体交付、许可和合规职责。 [官方 8-K，11/23](https://d18rn0p25nwr6d.cloudfront.net/CIK-0001045810/d56080ad-0d8b-401a-b284-e3308341659a.pdf)；[Reuters，11/23](https://live.euronext.com/en/financial-news/nvidia-reinstates-jensen-huang-ceo-amid-pressure-trump-investors)

### 4. CrowdStrike 拟以约 439 亿美元企业价值收购 Zscaler

**领域：政策与商业 / 应用｜11 月 23 日宣布。** 双方签署全股票交易协议，每股 Zscaler 换取 1.135 股 CrowdStrike。预计在 CrowdStrike **2028 财年下半年**交割，仍需股东及监管批准；交割前继续独立运营。

**公司主张与判断：**双方希望把终端、身份与网络遥测统一，用于保护 Agent 的执行位置和外部连接；这仍是整合目标，未证明已经降低攻击成功率。对企业安全采购，影响在于供应商集中、套餐议价和数据整合路径，当前应核对合同及迁移承诺，避免把并购公告当成现成的一体化产品。 [公司协议公告，11/23](https://ir.crowdstrike.com/news-releases/news-release-details/crowdstrike-acquire-zscaler-bringing-network-security-and-zero)；[Reuters，11/23](https://www.investing.com/news/stock-market-news/crowdstrike-bets-on-network-security-with-439-billion-zscaler-deal-5044856)

### 5. Applied Digital 新增 150MW 长期租约，交付仍有条件

**领域：Infra｜11 月 23 日披露，签署具体时刻未列。** 公司称与未具名投资级超大规模客户签订 18 年租约，基础期限合同收入约 **54 亿美元**；容量预计从 **2028 年上半年**开始交付，取决于建设、公用事业安排和监管批准，项目融资仍需推进。

**影响与判断：**客户仍在锁定多年后的容量，但合同收入不能当作现金到账或已投运容量。采购方应跟踪融资关闭、接电和验收里程碑；投资级租户身份未公开，履约能力尚无独立核验。 [公司公告，11/23](https://ir.applieddigital.com/_assets/_fd6b69ab052c3d450e233a0a1507ceeb/appliedblockchaininc/news/2026-11-23_Applied_Digital_Secures_New_150_MW_18_Year_Lease_165.pdf)

## 值得深入跟踪

1. **银行内部 Agent 的权限隔离。** Reuters 11/23 援引匿名业内人士称，多家银行正强化凭据隔离、运行限制和紧急停机；实施日期未逐家披露，也未报告这些银行遭遇同类失控事件。观察可审计的身份、不可改写日志及停机后的业务接管，而非仅靠提示词约束。 [报道](https://d2233.cms.socastsrm.com/2026/11/23/exclusive-some-us-banks-tighten-ai-agent-controls-on-concern-about-models-escaping-safeguards/)
2. **循环模型能否降低每个成功任务的成本。** 观察 GLM-5.4 普通 API、价格、权重及固定预算独立测试，尤其是长思考导致的超时；目前不能据架构宣称普遍胜出。
3. **自动批准能否经受真实维护周期。** Claude Ship 的关键验证是上线后漏检、回退、人工复核时长和审查账单；需比较同类变更，避免把 PR 数量增长直接当作质量提升。

## 今日推荐

- **试用 Gemini 文件切片。** 11/23 新增 Office/OpenDocument 原生上传与按页、单元格、媒体区间读取，按实际检查部分计 token；上传整文件的大小限制仍适用。适合文档 Agent 比较全量读取与局部读取的任务成功率和总费用，降本幅度尚无独立通用验证。 [官方说明](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)
- **阅读 vLLM 的 NVMe KV 缓存实验。** 11/23 文章（仅日期，精确时间边界未确认）中，AMD 与 Embedded LLM 自测：特定 MI355X、Kimi-K3 负载下，同容量 NVMe 与 DRAM 池吞吐相差不超过 1%。值得复现实验，但仍需 DRAM 缓冲，轻负载延迟、SSD 写寿命和未合入补丁限制都应纳入评估；并非普遍替代结论。 [实验与复现说明](https://vllm.ai/blog/2026-11-23-skip-the-dram-tier)
- **在测试 VM 体验 Shirudo。** OpenAI 与 Cisco 于 11/23 开源 eBPF 运行时，让运维批准的临时防护在服务运行中加载，填补正式补丁部署前的空窗。项目仍为预发布，生产目标机需要定制内核与 TPM 支持。Codex 生成防护拦截 Java4Shell 的结果来自公司受控测试，尚无独立生产验证；重点检查误拦截、签名验证与撤销流程。 [发布](https://openai.com/index/introducing-shirudo/)；[代码与运行要求](https://github.com/shirudo-dev/shirudo)
