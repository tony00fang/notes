## 重点动态

### 1. Haiku 5.5：低价子 Agent 值得立即评测

**领域：模型 / 推理 / Coding｜10 月 7 日发布。** 提示不超过 10 万 tokens 时，每百万输入／输出分别为 **0.10／0.50 美元**；超过该长度则为 0.50／2.50 美元。模型新增可调推理强度；Sonnet 5.5 缓存读取同步从每百万 0.20 降至 0.10 美元。

**判断：** 摘要、分类、上下文压缩和子任务分派的经济性明显改变。厂商所称平均节省 75% 涉及分词器和请求分布，不代表每个任务；独立测评已有结果，仍不能代替企业工作负载验证。建议按推理强度实测正确率、首字等待及重试后的总成本。

来源：[Anthropic](https://www.anthropic.com/claude-haiku-5-5)、[Reuters](https://www.marketscreener.com/news/anthropic-launches-third-claude-5-5-model-expanding-ai-lineup-before-planned-ipo-ce785ddedd89f722)（10/7）；[Artificial Analysis](https://artificialanalysis.ai/models/claude-haiku-5-5/)（本次核验）。

### 2. ChatGPT 推出 Intelligent UI，免费档随后扩展

**领域：应用 / 模型｜10 月 7 日开始推出。** 付费 Chat 用户率先获得交互图表、按钮、表单及即时小工具，Free／Go 从 10 月 8 日开始分批开放；本次不更换 Work、Codex 模型。

**公司自评：** GPT-6 Instant 相比 GPT-5.6 Instant，在需搜索的问题中平均提前 44% 开始回答，衡量的是开始输出时间，并非完成任务快 44%。**判断：** 产品团队值得测试“回答即可操作”的体验，同时检查图表数据、计算逻辑和交互后的事实一致性。企业可用性仍受管理员设置影响。

来源：[OpenAI 公告](https://openai.com/index/gpt-6-for-everyone/)、[系统卡](https://deploymentsafety.openai.com/gpt-6-october)（10/7）。

### 3. AWS GPU 预留新价生效：预算需要重算

**领域：Infra｜10 月 7 日生效，最迟 10 月 1 日已有预告报道。** Capacity Blocks 当前非 GovCloud 所列区域，B300 为 **16.146 美元／GPU·小时**，B200 为 14.208，H100 P5 为 5.970。官网实时表已更新；这次新增信号是执行价格，不能包装成首次宣布。

**判断：** 模型 API 降价不会自动降低自建训练、推理集群成本。Capacity Blocks 按购买时价格锁定，既有订单不因此补差价；也不能将这张表套用于所有按需实例。建议重新比较任务时长、利用率和预留方案，区分单 GPU 与整实例报价。

来源：[AWS 价格表](https://aws.amazon.com/ec2/capacityblocks/pricing/)（10/7 更新）；[此前报道](https://ca.investing.com/news/stock-market-news/wells-fargo-reiterates-amazon-stock-overweight-on-aws-pricing-power-93CH-4861665)（10/1）。

### 4. RTX Spark 开放预订，本地算力开始有明确交期

**领域：Infra / 应用｜10 月 7 日开放预订。** Surface Laptop Ultra **2,599 美元起**，10 月 16 日开始供货；RTX Spark Dev Box 为 5,999 美元，仅美国预订，11 月开始发货。平台最高支持 128GB 统一内存。

**证据边界：** “1 PFLOP”是厂商稀疏 FP4 理论值；128GB 是整机共享内存，GPU 可用量更少，也不是起售价配置承诺。**判断：** 本地模型开发者获得新选择，但采购应等待真实模型吞吐、长上下文内存、持续功耗及 Windows Arm 工具兼容性实测。

来源：[微软规格与交期](https://blogs.windows.com/devices/2026/10/07/pre-order-our-most-powerful-surface-devices-ever/)、[NVIDIA 平台说明](https://blogs.nvidia.com/blog/local-ai-rtx-spark-microsoft-windows-event/)（10/7）。

### 5. Copilot 本地沙箱 GA，企业旧策略需要检查

**领域：Coding｜10 月 7 日发布。** CLI、桌面应用及 VS Code Agent Host 会话获得跨系统本地沙箱，不额外收费；**默认关闭**。它限制工具的文件、网络和凭据访问，但属于轻量隔离，部分内置文件工具仍依靠进程内策略检查。

**行动：** VS Code 1.141 中，旧策略 `ChatAgentSandboxEnabled` 在 Agent Host 里变为可覆盖默认值；需强制执行的企业应迁移托管设置，并检查禁止绕过、宿主不支持时停止执行的行为。正式可用不等于获得独立安全边界，团队应验证实际拒绝记录。

来源：[GitHub 公告](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)、[隔离边界](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/about-cloud-and-local-sandboxes)、[VS Code 说明](https://code.visualstudio.com/updates/v1_141)（10/7）。
