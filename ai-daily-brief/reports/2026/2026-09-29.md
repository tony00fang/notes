## 重点动态

### 1. Sonnet 5.5：值得立即评测的效率升级
**领域：模型 / Coding / 推理｜9 月 28 日**

**事实**：新模型已发布，输入／输出仍为每百万 token 2／10 美元。**公司自评**：输出速度提高逾 30%，多数任务成本最多降低 30%；这不是 API 单价降价，也不能推成全面超越 Opus。

**独立证据**：Vals 在主要使用 max effort 的评测中测得综合分 69.22%，每测试成本 20.80 美元；Opus 5.5 为 69.69%、32.77 美元。但该测试允许服务端回退到 Sonnet 5；将回退辅助任务计为失败，Sonnet 5.5 综合分变为 68.89%，网络安全任务受影响更大。

**判断与行动**：适合开发团队用真实缺陷修复和代码审查重测成功率、总费用与耗时。迁移文档明确：关闭思考的旧参数会报错，改用仅关闭前置思考的 `between_tools`，且只支持 low／medium／high；强制工具选择 `any/tool` 也不再支持。不要只替换模型名。

来源：[官方发布](https://www.anthropic.com/claude-sonnet-5-5)、[Vals 实测](https://www.vals-ai.com/models/anthropic_claude-sonnet-5-5)（均 9 月 28 日）；[迁移文档](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)（本次查阅）。

### 2. NVIDIA 将 Agent 隔离推进到独立硬件层
**领域：Infra / 应用 / Coding｜9 月 28 日**

**事实**：Open Agent Safety Platform 组合既有 OpenShell 开源运行时与 Sentry 参考架构。前者在 Agent 进程外执行权限策略；后者可在 BlueField-4 DPU 上通过 DOCA 独立监控、执行策略。OpenShell 本身不要求 BlueField。

**公司主张**包括毫秒级隔离越界 Agent，本次未找到独立攻防复现，公告也不代表所有硬件组件已普遍交付。**判断**：长时间运行的 Agent 需要外部可执行约束，平台的重要性在控制位置。运维团队应先测试网络出口、子进程和凭据权限被拒绝时的行为，并记录误拦截与任务完成率。

来源：[发布公告](https://nvidianews.nvidia.com/news/open-agent-safety-platform)、[技术架构](https://developer.nvidia.com/blog/nvidia-open-agent-safety-platform-a-reference-for-continuous-in-silicon-agent-monitoring/)（9 月 28 日）。

### 3. AMD 拟收购 World Labs，模型与芯片协同加深
**领域：Infra / 政策与商业｜9 月 28 日披露**

**事实**：AMD 公布约 82 亿美元全股票收购协议；SEC 文件显示实际签约日是 9 月 26 日。交易预计年底完成，仍需监管批准及满足交割条件；李飞飞将在交割后出任执行副总裁兼首席科学家。Reuters 交叉确认交易条款。

**判断**：空间智能、机器人与仿真模型可能更直接参与 AMD 硬件和软件路线设计，对相关开发团队有长期影响。但“协同”目前是战略预期，没有现成性能优势证据；应跟踪交割、模型开放政策与可用工具链，而非据此立即改换算力供应商。

来源：[AMD](https://newsroom.amd.com/news/amd-acquire-world-labs/)、[SEC 8-K](https://www.sec.gov/Archives/edgar/data/2488/000000248826000182/amd-20260926.htm)、[Reuters](https://finance.yahoo.com/news/amd-acquires-world-labs-8-203900428.html)（9 月 28 日）。

### 4. 佛罗里达申请对 OpenAI 模型开发设置外部安全审批
**领域：政策与商业｜9 月 28 日**

**事实**：州总检察长在既有诉讼中提交临时禁令动议，要求限制未经独立第三方安全措施及批准的模型开发，并禁止向州内未成年人提供 ChatGPT 等行为。动议列举的违法与危害仍是**原告指控**，申请不等于禁令生效。Bloomberg Law 引述 OpenAI 回应称，希望规则适用于整个行业。

**判断**：此前的事故披露正在转化为具体司法请求；影响可能延伸至开发审批、年龄控制与产品拟人化设计。企业应关注听证、裁定及适用范围，不能将它理解为全国停训令。

来源：[盖章动议副本](https://aboutblaw.com/bmXh)、[Bloomberg Law](https://news.bloomberglaw.com/product-liability-and-toxics-law/florida-sues-to-block-new-openai-models-without-safeguards)（9 月 28 日）。

### 5. Meta 成立企业 AI 业务
**领域：应用 / 政策与商业｜9 月 28 日**

**事实**：Meta 宣布 Enterprise Platform，由来自 MongoDB 的 CJ Desai 领导、向 Zuckerberg 汇报，计划将 Muse、Business Agent、API 和编程工具推向企业。CNBC 核实任命。公告未给出整套产品的正式可用日期、价格或服务承诺。

**判断**：企业 Agent 采购可能新增大型供应商，但组织成立不等于产品已成熟。采购方应等待可订购服务、数据权限及客户实绩，再判断替换价值。

来源：[Meta](https://about.fb.com/news/2026/09/launching-meta-enterprise-platform/)、[CNBC](https://www.cnbc.com/2026/09/28/mongodb-meta-cj-desai.html)（9 月 28 日）。
