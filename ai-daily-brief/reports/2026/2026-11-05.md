## 重点动态

### 1. Conductor 加入 Meta，云端用户面临迁移期限
**领域：Coding / 政策与商业**

**事实**：Conductor 宣布加入 Meta；TechCrunch 获 Meta 确认。11 月 4 日停止新注册及下载，13 日云工作区只读，20 日关闭并开始删除云数据；本地版本继续接收新模型及关键修复至 2027 年初，随后逐步退出。**判断与行动**：并购直接改变工具存续期。现有用户应在工作区选择“Transfer to local”，或到 Settings → Account → Export data 导出，并验证聊天记录与代码均可恢复。

来源：[官方公告与时间表](https://www.conductor.build/announcement/)、[TechCrunch 报道](https://tech.yahoo.com/ai/meta-ai/articles/meta-acquires-ai-coding-startup-211056941.html)，11-04。

### 2. Ripple-65B Preview：可下载的编程模型与训练配方披露
**领域：模型 / 训练 / 推理**

**事实**：Ricursive 发布 65B 稠密模型，采用 Apache 2.0 许可，提供指令模型、基础模型及 NVFP4 版本。模型卡披露预训练、长上下文、SFT、RL 阶段，为自托管和后训练研究提供新对象。**公司自评**：Terminal-Bench 2.1 得分约 80.5；尚无独立复现，且比较表混合其他模型官方成绩与内部测量，评测执行框架会影响结果。**判断与行动**：开放基础模型还让研究者能区分预训练与后训练带来的变化，但“基础模型可下载”不等于训练数据与全过程都可复现。值得在真实仓库验证；总参数少于大型 MoE，并不意味着激活计算量更低，不能直接推导同等倍数的推理省钱效果。

来源：[模型卡与权重入口](https://huggingface.co/ricursiveAI/Ripple-65B-Preview/raw/main/README.md)、[许可证](https://huggingface.co/ricursiveAI/Ripple-65B-Preview/blob/main/LICENSE)，11-04。

### 3. SWE-2 Flash：低价高速值得测试，权重仍未公开
**领域：Coding / 模型 / 训练**

**事实**：Cognition 在 Devin Desktop、CLI 提供 SWE-2 Flash，以 Inkling-Small 为基础，增加中期训练后再做强化学习；权重仅计划向可信伙伴与研究机构受控分享。**公司主张**：价格为 SWE-2 的五分之一、速度约三倍；自家表中部分编程成绩上升，另一些低于 SWE-2，未见独立验证。**判断与行动**：适合用代码审查、文档更新、常规修复做对照试验，记录成功率、端到端等待时间、重试和人工返工后的成本。它的训练说明也提示，任务指令、运行环境和验证器质量可能与强化学习配方同样重要；不要把“对比开放模型”误读为它已开放权重。

来源：[Cognition 技术发布](https://cognition.com/blog/swe-2-flash)，11-04，仅日期。

### 4. Images 2.6：GIF 与更细粒度编辑成为产品能力
**领域：应用 / 模型**

**事实**：OpenAI 宣布在 ChatGPT、Codex 与 API 提供 Images 2.6；支持 GIF，API 增加图像标记、SVG 导出和控制规划程度的 complexity 参数，区分偏速度的 Flare 与偏质量的 Sunburst。**公司主张**：图像生成更快、编辑一致性更好，尚无本次核验可确认的独立效果测量。**判断与行动**：设计、营销和游戏团队可测试角色连续编辑、品牌细节保持及矢量文件可编辑性，记录返工率；演示效果不能替代生产验收。

来源：[OpenAI 官方发布](https://openai.com/index/introducing-images-2-6/)，11-04，仅日期。

### 5. Google 马来西亚投资扩张：150 亿美元是未来计划
**领域：Infra**

**事实**：Google 宣布 2027—2028 年投入 150 亿美元，涵盖数据中心、能源、水资源和人才；Bernama 独立报道现场公告。Elmina 首个园区已运行，新园区及马来西亚 Cloud region 尚待交付。**公司计划**还包括向电网增加超过 1GW 清洁能源，这不是数据中心 IT 负载，也不是已投运容量。**判断与行动**：东南亚企业获得新的中期供给预期；采购决策仍应等待区域上线、具体服务及容量承诺，不能把总投资全算作 AI 算力。

**领域：政策与商业 / 应用**

**事实**：OCC 发布供检查人员使用的框架，强调按潜在后果、授权程度及人工监督评估银行 AI 用例；不把 AI 单列为风险类别，也不要求独立风险偏好。公告明确不建立新的可执行标准或监管要求。文件中的“Super Intelligence”是其涵盖 AI 的用语，不能据此判断超智能已经出现。**判断与行动**：金融 Agent 团队可据此检查交易权限、审批边界和审计记录，重点证明出错时能限制影响，而非仅展示模型分数。
