## 重点动态

### 1. Gemini 4 Carbon 发布：能力提升与有限开放并存

**领域：模型 / Coding / 推理｜10/28 17:00 UTC 发布。** Google 宣布 Carbon，本周先向部分网络安全防御者开放，再通过 Fairwind 扩展至可信伙伴，普通开发者与消费者访问仍待推出。Artificial Analysis 独立评测的 High 版本在 v5 综合指数得到 **59 分**；Google 关于长时工程任务、安全代码和漏洞修补的提升属于**公司自评**，其网络安全基准明确在未启用防护措施时测试。

公布的优惠价为每百万输入／输出 token **2／10 美元**，优惠结束后为 **4／20 美元**，未给结束日期。**判断与行动：** 值得安全与代码团队跟踪，但不能把榜单和零攻击成功率样本视为安全保证。获得访问后，应测自己的补丁验收率、越权率及每个完成任务成本。[Google 公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)、[独立评测](https://artificialanalysis.ai/models/gemini-4-carbon)（10/28 发布／本次读取）。

### 2. GitHub Fusion 正式提供，PR 修复进入云端闭环

**领域：Coding / 应用｜10/28 发布。** Copilot Fusion 在 VS Code、Copilot app、CLI 和 JetBrains 正式提供，通过单模型、逐级升级或交叉评审处理任务；管理员的模型允许策略继续生效。**每个实际使用的模型均按其标准费率计费**，付费计划的 30% 折扣只是限时优惠。降本及性能优势仍按公司主张处理。

同日 Agent Merge 接入 GitHub 网页 PR，可在云端修复失败的 Actions 和合并冲突，面向付费计划并受组织策略约束；与自动合并结合后，仍须满足仓库合并要求。**判断与行动：** 工程团队可立即用低风险任务对照试验，记录每个获准合并 PR 的总成本、返工与人工审核时间。[Fusion](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/)、[Agent Merge](https://github.blog/changelog/2026-10-28-agent-merge-watches-and-fixes-pull-requests-in-the-cloud/)（均 10/28）。

### 3. 云财报：需求强劲，交付节奏与现金流更值得看

**领域：Infra / 政策与商业｜10/28 财报披露，数据期截至 9/30。** 微软披露 Azure 收入同比增长 **48%**；Reuters 报道当季自由现金流 **186 亿美元**，资本开支 **452 亿美元**低于预期，公司解释为第三方容量交付延期，而非削减投入计划。Alphabet 披露 Google Cloud 收入 **307.09 亿美元、同比增长 103%**，其中 TPU 系统销售也有重要贡献；集团自由现金流为 **负 90.65 亿美元**。

**判断与行动：** 云采购与投资观察应同时看实际可交付容量、收入构成和现金回收，不能直接比较两个增长率，更不能把延期支付当作永久节省。上述数据也不足以单独证明生成式 AI 项目的回报。[微软财报](https://news.microsoft.com/source/2026/10/28/microsoft-announces-first-quarter-results-2/)、[Reuters 微软报道](https://b975.com/2026/10/28/microsoft-beats-quarterly-cloud-revenue-estimates/)、[Alphabet 财报](https://s206.q4cdn.com/479360582/files/doc_financials/2026/q3/2026q3-alphabet-earnings-release.pdf)（均 10/28）。

### 4. 英国以数据中心公共责任换取重点支持

**领域：Infra / 政策与商业｜10/28 预算公告。** Data Centre Covenant 要求寻求额外政府支持的数据中心满足能源成本、社区收益、环境、就业与安全条件；政府计划优先安排战略项目的电网连接。预算同时提出投入 **4,000 万英镑**建立 National Agentic Security Unit，用于监测、调查及响应失控 Agent 事件。

**判断与行动：** 项目竞争将更依赖电力接入与本地履约能力，预算承诺并非新增机房已经通电。英国算力项目应核对资格标准、接电时间及公共责任成本；安全团队关注新机构权限与事故报告接口。[英国预算原文](https://www.gov.uk/government/publications/budget-2026-document/budget-2026-html)、[Reuters](https://www.aol.com/articles/uks-healey-offers-grid-access-132728000.html)（均 10/28）。

### 5. FTC 追查个性化价格与薪酬的数据链

**领域：应用 / 政策与商业｜10/28 发出资料令。** FTC 要求 Walmart、Uber、Delta 等九家公司提交资料，研究个人数据如何用于定价、报酬和工作机会；收令后有 **45 天**回应。调查由中间技术供应商转向实际决策企业，涵盖数据输入、工具和流程。这是研究取证，**不是违法认定或全面禁令**。

**判断与行动：** 使用 AI 定价和用工系统的平台，应能追溯数据来源、规则版本与个体决策；以第三方算法运行并不能替代自身解释能力。Reuters 同时记录部分企业否认实施个性化定价，不能把被点名等同于事实成立。[FTC 原文](https://www.ftc.gov/news-events/news/press-releases/2026/10/ftc-launches-personalized-pricing-compensation-inquiry)、[Reuters](https://new.streetinsider.com/General%2BNews/Exclusive-US%2BFTC%2Bdemands%2BWalmart%2C%2BUber%2C%2BDelta%2Band%2Bothers%2Bhand%2Bover%2Bdata%2Bon%2Bpersonalized%2Bpricing/27248351.html)（均 10/28）。

## 值得深入跟踪

1. **Carbon 能否把评测优势转成生产收益？** 看公开访问日期、防护开启后的效果、优惠结束时间，以及独立长任务故障记录。
