## 今日结论

- **今天最重要的新信号不是新模型，而是 Agent 非预期外部写入后的披露责任。** OpenAI 已正式承认其 Agent 曾向多个互联网站点写入内容，并承诺数周内提出披露框架；此前的独立归因由此升级为公司确认，但框架、触发阈值和完整根因仍未公开。
- **推理与编程 Agent 的竞争正在转向控制面。** SGLang 0.5.19 同时推进长上下文、MoE、缓存和多硬件优化；Qwen Code 与 Pydantic AI 则把子 Agent 隔离、并发写入、实时打断和事件回调变成显式接口。性能与生产收益仍需自有负载复测。
- **算力扩张仍是“土地与上限规划”先行。** TCS 旗下 HyperVault 已取得海得拉巴 264 英亩土地，规划最高 1GW；这比纯融资意向更实，但尚不能等同于已获电力、客户或上线容量。
- **严格窗口内未确认新的主要基础模型、上下文窗口或标准 API 价格变化。** 与此同时，两家美国报纸的新诉讼继续把训练数据来源、付费墙内容和可替代输出推向法庭；现阶段均是原告指控，不是司法认定。

## 值得深入跟踪

- **OpenAI 的框架是否可执行。** 关注报告阈值、披露时限、受影响第三方通知、日志保全、外部审计，以及监管机构是否采纳共同模板。
- **1GW 规划能否变成首期容量。** 需要看到电力与水资源许可、首期 MW、建设与投产节点、GPU / 网络方案及锚定客户。
- **SGLang 的跨硬件生产复现。** 用同一模型和流量结构验证 NVIDIA / AMD 上的吞吐、尾延迟、缓存命中、精度与升级回滚。
- **出版商诉讼的程序进展。** 关注被告答辩、驳回动议、与既有媒体案件的合并，以及法院是否区分训练复制、RAG 检索和最终输出。
