## 今日结论

观察窗口：2026-11-17 08:03:58—11-18 08:03:58（北京时间）。七个方向均完成扫描；重点为本窗口发布，另列一项“7 天持续影响”研究阅读。

- **模型降价有实质变化，但编程能力未全面同步提升。** GPT-6.2 Astra 下调输入、输出单价；独立评测显示综合能力进步，Coding Agent 指数却持平。
- **企业 Agent 转向持续执行与共享上下文。** 微软发布 Autopilot、Workspaces，但当前开放范围有限，不能按全面可用规划迁移。
- **算力需求继续兑现为收入，供给仍受长期约束。** NVIDIA 财报强劲；Google 的新地热购电协议最早到 2030 年供电。
- **今天值得做的是任务级复测。** 比较模型时同时记录质量、返工与成本；促销价、评测框架和推理档位都可能改变结论。

## 重点动态

### 1. GPT-6.2：正式降价，综合进步与编程退步同时出现
**领域：模型 / Coding / 推理｜显著价格变化**

**事实：**11 月 17 日，OpenAI 发布 Astra、Sol，开放至 ChatGPT Work、Codex 和 API。Astra 每百万输入／缓存输入／输出为 8／0.40／40 美元，输入输出较前代低 20%，缓存低 60%；Sol 维持原价。**独立测量：**Artificial Analysis 报告 Astra 综合指数提高 5 分、Sol 提高 2 分；但在 Codex、max 档位的 Coding Agent 指数中，Astra 持平，Sol 下降 3 分，主要问题是代码问答遗漏事实。**判断与行动：**这是成本与能力组合的变化，不能概括为所有任务升级；开发团队应先复测仓库理解、复杂修复和最终合并率。厂商专业交付能力主张不能替代本地验收。

来源：[OpenAI 发布及定价](https://openai.com/index/introducing-gpt-6-2-astra-sol/)、[AA 独立评测](https://artificialanalysis.ai/articles/openai-has-the-2-model-in-the-intelligence-index-with-the-release-of-gpt-6-2-astra-and-gpt-6-2-sol)（均 11-17）。

### 2. NVIDIA 季度营收翻倍，下一季展望须考虑额外一周
**领域：Infra / 政策与商业｜产业规模信号**

**公司披露：**截至 10 月 25 日的第三财季营收 1,158 亿美元、同比增 103%；数据中心收入 1,076 亿美元。11 月 17 日公布的下一季收入指引为 1,300 亿美元、上下浮动 3%，不假设中国数据中心计算收入，并且该季度多一周。Reuters 确认业绩与展望超过市场预期；财务报表仍属未经审计。**判断：**这是实际销售的新增证据，但不能证明下游 AI 项目已经盈利。云采购者应关注可交付机架、利用率和客户回款，避免把供应商增长直接当作应用需求回报。

来源：[NVIDIA 财报](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-third-quarter-fiscal-2027)、[Reuters 报道](https://www.streetinsider.com/Reuters/Nvidia%2Bearnings%2Bbeat%2Bestimates;%2Battention%2Bturns%2Bto%2Bcall/27364633.html)（11-17；业绩期间早于发布日）。

### 3. Copilot 从个人对话扩展至持续运行与团队工作区
**领域：应用｜企业工作流变化**

**事实：**Ignite 公告中，Autopilot 通过 Frontier 计划开始推出，在企业租户内拥有独立身份、记忆和工具访问，可处理周期性工作；Workspaces 也通过 Frontier 开放，用共享材料组织团队工作。把个人 Autopilot 带入 Workspaces 仍是“即将推出”。**公司主张：**管理员可识别、管理 Agent 行动；尚无独立生产效果核验。**判断与行动：**价值在于任务能持续推进，难点则是权限随时间变化、多人交接及失败恢复。企业试点应先选可核对结果的周期性流程，记录异常接管和人工复核成本，不能只看生成量。

来源：[Microsoft Ignite 功能与开放范围](https://news.microsoft.com/events/ignite/2026/book-of-news/)（11-17）。

### 4. MAI Code 2 入场，但低价比较含五折促销假设
**领域：模型 / Coding｜值得开发者试用**

**事实：**Code 2 与 Flash 已在 GitHub Copilot 提供；Flash 在 Foundry 为限量预览。**公司自评：**四项日常编程基准平均，Code 2 达到 GPT-6.1 Sol 的 98% 表现、使用 40% 成本。然而其脚注明确使用五折促销价，测试采用指定框架、max 档位，多数测试不启用子 Agent；并非长期价目表或所有编程任务的等效替代。**判断与行动：**适合把常规修改分流给便宜模型，但先以促销结束后的费用估算，并单独测跨文件修改、测试遗漏和审查返工。公司也明确尚未针对基础科研和超长 Agent 任务优化。

来源：[微软发布与评测脚注](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)（11-17；性能比较尚无独立整体核验）。

### 5. Google 签下 50MW 超热地热购电协议
**领域：Infra / 政策与商业｜未来供给信号**

**事实：**Quaise 宣布 Google 将购买俄勒冈 Project Obsidian 的 50MW 电力，最早 2030 年开始；首期使用常规钻井，毫米波钻井属于第二阶段计划。OPB 向双方核实交易，电价未公开，项目还需建设输电线路。**判断：**长期买方为新型稳定电源提供商业支撑，但签约不等于发电成功，更不能写成毫米波钻井已商业验证。数据中心规划者应跟踪井产能、许可、并网和实际供电日期，不把远期合同计入近期可用容量。

来源：[Quaise 公告](https://www.quaise.com/news/quaise-energy-signs-50-mw-geothermal-power-purchase-agreement-with-google)、[OPB 独立采访](https://www.opb.org/article/2026/11/17/google-oregon-bend-la-pine-superhot-rocks-technology-energy-power/)（11-17；合同签署具体时刻未公开）。

## 值得深入跟踪

1. **更便宜的模型是否真的减少交付成本？** 观察相同任务、相同工具下的遗漏率、返工轮数和通过验收的总费用；尤其复核 GPT-6.2 Sol 的代码问答弱项及 MAI 非促销成本。
2. **长期 Agent 能否安全交接？** 观察 Frontier 试点中的权限撤销、失败恢复、多人共享状态与真实业务成功率，而非把“能持续运行”当成可靠性结论。
3. **出口合规能否形成可核验证据？** NVIDIA 于 11 月 17 日成立董事会级国家安全与出口管制监督委员会，并将聘请外部专家。下一步关注审计结果、客户核查和披露，委员会成立本身不证明既往问题已解决。[官方公告](https://nvidianews.nvidia.com/news/nvidia-board-of-directors-establishes-national-security-and-export-control-oversight-committee)
