# AI Daily Brief｜2026-09-12

- **开发者可立即验证的变化**：Copilot 审查开始运行构建、测试并汇总多个 Agent 的发现；评估重点应是实际修复与误报，而非评论数量。

## 重点动态

### 1. Copilot 将代码审查扩展为执行验证

**领域：Coding｜24 小时。** GitHub 于 9 月 11 日更新 Copilot code review：可在 Agent firewall 后使用 SDK 的 shell 工具运行构建、测试和定向脚本；Lite 档采用多个 Agent 汇总审查；后续提交解决问题后可自动关闭评论。

**公司自评**：实验中，每次审查得到处理的高严重度评论数增加 47%，审查成本约降 8%。这不是准确率提升，也不是公开价格下调，尚无独立核验。**判断与行动**：工程团队可拿历史缺陷 PR 对照复测，同时记录漏报、误报、执行费用和错误关闭评论；执行能力更强也要求检查审查环境的工具权限。来源：[GitHub 公告，9/11](https://github.blog/changelog/2026-09-11-auto-resolution-and-analysis-updates-in-copilot-code-review/)。

### 2. DeepSeek Pro 服务计划修订，官方页面尚未统一

**领域：模型 / 推理｜7 天持续影响，更正跟踪。** 当前 API 首页及价格页明确：9 月 14 日之后继续提供 V4 Pro，计费方式不变，后续变化另行通知；但 9 月 10 日发布页仍写届时将 Pro 请求转到 V4.1 Flash。**事实边界**：这是本次核查发现的文档差异，修改时间未披露，不能断言精确发生于过去 24 小时；未来服务承诺尚待实际核验。

**判断与行动**：昨日“9/14 必然切换”的预期应撤回。使用 Pro 的团队应复核服务通知、实际响应和账单；旧 Flash 别名已转到 V4.1 Flash 的说明仍然存在，不应把 Pro 的保留理解为全面回滚。来源：[当前 API 文档，9/12 查阅](https://api-docs.deepseek.com/)、[价格页](https://api-docs.deepseek.com/quick_start/pricing/)、[9/10 原公告](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)。

### 3. 阿联酋 5GW AI 园区据报考虑分散布局

**领域：Infra / 政策与商业｜24 小时新披露。** Reuters 9 月 11 日援引六名知情人士称，原拟集中于阿布扎比的 5GW 项目可能改为多地点布局，并加强物理防护。方案审查始于此前冲突后，并非当天才启动。G42 回应工程仍按计划推进，具体设计持续审查；Reuters 无法确认最终方案、成本和工期。

**媒体报道，尚待确认**，没有第二份独立确认。**判断**：这可能改变集群集中度、跨站网络和容灾成本，但不能据此宣告项目停建或延期。采购方应关注正式选址、首期交付和容量保障条款。来源：[Reuters 英文报道，9/11](https://currently.att.yahoo.com/att/exclusive-uae-revises-ai-data-090755337.html)。

### 4. 欧盟 CRA 报告义务开始适用，平台初版上线

**领域：政策与商业 / Coding｜24 小时。** ENISA 9 月 11 日宣布报告平台投入初始运行；受 CRA 覆盖的数字产品制造商须报告被实际利用的漏洞和严重安全事件，知悉后最迟 24 小时预警、72 小时提交通知。主要产品要求及开源软件 steward 的相应报告义务从 2027 年 12 月起适用，不能一概提前。

**官方事实**，报告时限另有独立法律解读交叉支持。**判断与行动**：向欧盟提供受覆盖 AI 软件或设备的团队，应确认适用范围、责任人和事件升级流程。平台初版没有 API，不能假定现有自动化已完成申报。来源：[ENISA 上线公告，9/11](https://www.enisa.europa.eu/news/the-cra-single-reporting-platform-is-launched)、[FAQ，9/11 更新](https://www.enisa.europa.eu/topics/product-security/single-reporting-platform-srp/frequently-asked-questions)、[Jones Day，7 月法律解读](https://www.jonesday.com/en/insights/2026/07/eu-cyber-resilience-act-24hour-reporting-duties-start-september-11-2026)。

### 5. Salesforce 将岗位 Agent 接入长任务运行时

**领域：应用｜24 小时。** 9 月 11 日发布的 Agentforce 组合覆盖销售、客服、电商及后台；新运行时提供跨会话记忆、持久执行和动态调整。Hunter 首先使用，目前是试点，计划 11 月全面可用；多 Agent 编排现已全面可用，不能把整个产品组合都写成已支持数周自治。

**公司主张**：跨天、跨周推进目标的可靠性及客户效果尚无独立核验。**判断与行动**：Salesforce 客户可评估现有数据与流程如何接入，并先验证暂停、恢复、人工批准和审计记录；按已开放能力决定试点，不以未来路线图估算回报。来源：[Salesforce 公告，9/11](https://www.salesforce.com/news/stories/agentforce-job-ready-ai-agents/)。

## 今日推荐

- **试用 Claude Code 插件评估**：9/11 的 2.1.269 release notes 列入 `claude plugin eval`，可输出评分及 JSON/HTML 报告。先看 `--help`，为常用插件建立行为回归集；“可复现”是工具承诺，仍需控制模型和环境。[官方版本说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)。
- **阅读 MoE 重复数据研究｜7 天持续影响**：9/10 提交的论文发现，在其测试规模内，MoE 对重复数据更易过拟合；正则化能缓解，不能替代独有数据。训练团队应同时核算独有 token 与重复次数；结论尚无独立复现，不可直接外推到前沿规模。[论文与方法](https://arxiv.org/html/2609.11917v1)。
- **查看 NASA–IBM 月球基础模型｜7 天持续影响**：9/10 开放的模型整合多传感器数据，用于陨石坑、火山地貌和冰候选区分析。适合研究多模态融合与少量数据适配；任务收益来自项目团队评估，预测冰候选区不等于发现冰。[IBM 技术介绍](https://research.ibm.com/blog/nasa-ibm-lunar-foundation-model)。
