# docs

这是一个用于沉淀长期笔记、分析文档、研究记录和写作模板的仓库。

## 目录结构

```text
.
├── README.md
├── templates/
│   └── analysis-note.md
└── notes/
    └── ai-infra/
        └── nvidia-five-layer-cake-and-moat.md
```

## 说明

### templates/
用于存放可复用模板。

当前包含：
- `analysis-note.md`：分析类、研究类、判断类文档模板。

### notes/
用于存放正式沉淀的主题笔记。

建议按主题继续分层，例如：
- `notes/ai-infra/`
- `notes/storage/`
- `notes/llm/`
- `notes/career/`
- `notes/productivity/`

## 文档约定

- 分析类文档优先使用模板撰写。
- 参考资料默认包含可点击原始链接，优先一手资料。
- 尽量区分“事实来源”和“作者判断”。
- 标题应尽量清晰、可检索。

## 后续建议

如果后续文档变多，可以继续增加：
- `assets/`：图片、附件
- `indexes/`：专题索引
- `archive/`：过时或历史版本文档
